# Portfolio Analytics Engineering

Analytics Engineering portfolio project: modeling in **dbt**, synthetic
data, and visualization in **Evidence.dev**, running on top of a free
**BigQuery sandbox**.

> ⚠️ All data in this repository is **100% synthetic**, generated by
> `scripts/generate_synthetic_data.py`. No data, business rule, or table
> name from any real employer is used here. This project is inspired by
> real professional experience with self-service dashboards, but was
> rebuilt from scratch using a generic domain.

## Why this project exists

I work as a Data Analyst building self-service dashboards (Metabase) and
doing data modeling in dbt. This repository is a public, simplified,
fictional-data version of my day-to-day stack, built specifically as a
portfolio piece — see [`docs/case-study.md`](docs/case-study.md) for the
full context behind the design decisions.

## Architecture

```
seeds (synthetic data)
└── customers.csv, transactions.csv, sessions.csv
│
▼
staging (models/staging/)
└── 1:1 with the source -- just cleaning, typing and renaming. Zero business logic.
│
▼
marts (models/marts/)
└── business logic, aggregations and metrics -- organized by domain
```

Three synthetic base tables feed **four different marts**, avoiding
rework and keeping a single, coherent data narrative (instead of 4
disconnected projects):

| Mart | Base tables used | Answers |
|---|---|---|
| `site_kpis` | `sessions` | Site engagement and traffic |
| `cohort_retention` | `customers`, `transactions` | Customer retention by acquisition cohort |
| `payments_funnel` | `transactions` | Payment conversion funnel |
| `customer_segmentation` | `customers`, `transactions` | Customer value segmentation |

## Stack

- **dbt Core** — transformation and modeling (staging → marts layers, tests, docs)
- **BigQuery sandbox** — data warehouse (production)
- **DuckDB** — used only locally for fast development/testing, no cloud credentials needed
- **Evidence.dev** — visualization layer, published as a free static site

## Running locally (DuckDB, no account needed)

```bash
pip install dbt-core dbt-duckdb
python3 scripts/generate_synthetic_data.py   # generates the CSVs in seeds/
dbt deps      # download packages (optional, see packages.yml)
dbt seed      # load the CSVs into the database
dbt run       # run the models (staging + marts)
dbt test      # run the 21 data quality tests
dbt docs generate && dbt docs serve   # interactive documentation
```

## Data quality tests

51 tests covering: `not_null`, `unique`, `accepted_values`,
`relationships` (referential integrity), and one **custom generic test**
(`accepted_range`, in `macros/generic_tests/`) written to avoid depending
on external packages.
